## 三、⚠/GBK P2 编码缺陷（新增 QA 发现，已验证修复）

### 现象
双击模拟（`subprocess` + PIPE 喂 `0` 退出）输出：
```
[异常] 'gbk' codec can't encode character '\u26a0' in position 972: illegal multibyte sequence

按回车键退出...
```
菜单整段打不出（仅重定向/管道场景命中）。

### 实测定级
- 源码 `.py` + `PYTHONIOENCODING=utf-8`：菜单完整输出、无 gbk 异常 ✅（对照组）
- exe + stdout **文件重定向 / 管道**：`'gbk' codec can't encode '\u26a0'`，菜单打不出 ❌
- exe + `PYTHONIOENCODING=utf-8` / `PYTHONUTF8=1`：frozen exe 均不生效，照样报错 ❌（PyInstaller bootloader 固定了 stdout 编码）
- **真机双击**走控制台 `WriteConsoleW(UTF-16)`，字符正常显示，缺陷不复现；仅「输出重定向到文件/管道」时命中
- **修复有效性已验证**：源码把 `banner += "\n  ⚠ 待办：\n"` 改为 `"\n  [!] 待办：\n"`，GBK 环境下菜单标题/请输入序号/待办全部正常打出、无异常 ✅

### 定级与修复建议
- **P2 建议级，不阻塞发布**。编码开发二选一：① `⚠` → `[!]`（最小改动）；② `main()` 入口加 `sys.stdout.reconfigure(errors="replace")`。改完无需重测全量，跑一次「重定向双击」即可。
