# 遮天法爬虫框架（zhetian-spider）

面向 TVBox / 影视仓 / py-drpy / drpy-node 的**高防御站点** py 源开发框架。以《遮天》"九秘→极道帝兵""八境功法"为隐喻组织爬虫能力，核心是配置驱动 + 防御等级自动路由 + 全 try-except 兜底。

## 标准执行流程（三步法，来自 AI开发流程.txt）

1. **建框架**：先读主文档，理解九秘体系、八境功法、v3.1 已知问题与绝对铁律
2. **对代码**：读战斗技能书 py，定位与目标站点防御等级匹配的境界类与九秘模块（不要从零写，基于框架改 DEFAULT_CONFIG 与适配层）
3. **接任务**：按提示词范式（站点信息→RealmAutoRouter 分析→DEFAULT_CONFIG→Spider 六接口→关键处理→验证）生成适配代码

## 九秘→能力速查

- 临（荒塔）：请求头/UA 轮换/域名发现
- 兵（诛仙四剑）：AES-CBC / XOR / Base64 解密
- 斗（吞天魔罐）：BS4+正则双引擎解析、标题清洗、图片修复
- 者（无始钟）：safe_call、指数退避重试
- 皆（仙珍图）：m3u8 广告分片识别清洗
- 阵（诛仙阵图）：本地 HTTP 代理服务器（m3u8/KEY URI 重写 + Referer 伪装）
- 列（虚空镜）：Referer 伪装、防盗链穿透
- 前（不死天刀）：13 层播放地址提取策略
- 行：随机延迟与节奏控制
- 逆（v3.1 新增）：Protobuf 编解码、SHA-256 签名重建

防御等级 0-4 逐级叠加帝兵；八境：轮海→道宫→四极→化龙→仙台→红尘仙（+洞天境/HTMX 专项）。

## 绝对铁律（摘自主文档，生成代码必须遵守）

1. 禁止不分析直接套模板；防御等级判定以 RealmAutoRouter 实测特征为准
2. 配置驱动：禁止硬编码 API 路径，一律走 DEFAULT_CONFIG
3. 全 try-except 分级兜底，禁止 `except Exception: pass` 静默吞错
4. 每个函数参数必须在体内使用；引号/括号 100% 闭合；零歧义
5. 缺失依赖优雅降级（pycryptodome 不在时退回破甲模块纯 Python AES）
6. 生成后必须自验语法 + TVBox 六接口（homeContent/categoryContent/detailContent/searchContent/playerContent/localProxy）

## 与本仓库其他写源技能的分工

- 普通 MacCMS v8/v10、采集 API、非加密非标站 → 优先 `spider-create`（v3.0 全类型骨架）或 `py-spider-v84`（v8.4 多模块六接口门禁），配套 `mcp_PY_MCP_S` 工具（analyze_website/one_click_spider/debug_selector/debug_play_link/test_interface/evaluate_source）
- 需要**框架级**能力（自动防御路由、本地代理、m3u8 清洗、纯 Python 解密链、TLS 指纹、签名逆向）→ 本技能
- 交付仍是 TVBox py 源；接口契约/parse 决策（直链 0/网页 1/webview 2）与通用规则以 py-spider-v84/spider-create 为准，本技能只补充破甲与框架能力，不覆盖契约
