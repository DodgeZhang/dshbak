## 1. 框架概述

遮天法 2.0 是面向 **TVBox / 影视仓 / py-drpy / drpy-node** 生态的爬虫源开发专家系统。

以《遮天》修炼体系为隐喻，将爬虫开发技术栈映射为"九秘→极道帝兵"和"八境功法"。2.0 在 1.0 基础上进行了架构级升级，核心亮点是**大帝级自动路由（RealmAutoRouter）**——一行代码即可自动分析目标站点、判定防御等级、匹配最佳策略。

### 2.0 核心升级

| 模块 | 1.0 | 2.0 | 影响 |
|------|-----|-----|------|
| **境界路由** | 手动选择境界类 | `RealmAutoRouter` 自动扫描 24 项特征→判定防御等级 0-4→自动实例化 | 一行 `create_spider_for(url)` 完成全流程 |
| **UA 池** | `self.ua_pool` 未定义（运行时崩溃） | 内置 8 条 UA 滚动轮换，多线程安全 | 修复致命 Bug |
| **本地代理** | 只构建代理 URL，无 Server 实现 | `DaoGong_ShenZang.start_proxy()` 完整 `http.server` + 皆字秘 m3u8 过滤 + 阵字秘 Referer 伪装 + 端口竞用 fallback | 道宫五藏全部激活 |
| **选择器** | 全部硬编码在源码 | 抽到 `realm_config.yaml`，支持热更新。单文件自带 `DEFAULT_CONFIG`，零外部依赖也可运行 | 站点改版无需改代码 |
| **日志** | `print()` 散落各处 | `ZheTianLogger` 结构化日志，按境界标记 | 调试效率大幅提升 |
| **监控** | 无 | `RequestStats` 请求成功率/均耗时/降级次数/分境界统计 | 批量跑站可量化 |
| **抽象层** | 境界类各自继承 `YuanTianShu` | `JieJingBase` 统一接口契约 + 内置 UA/Header 构建 | 新增境界只需实现 TVBox 六接口 |
| **继承链** | `YuanTianShu` → 各境界 | `JieJingBase` → `YuanTianShu`（线程安全 session）→ 轮海 → 道宫 → 四极 → 化龙 → 仙台 → 红尘仙 | 四极以上可复用下层能力 |
| **配置** | 无 | `RealmConfig` 单例 + YAML/JSON 双模式加载 + `_deep_merge` | 零依赖也可用内置配置 |
| **自包含** | 需外部依赖 | 单文件 `python 遮天法2.0.py` 即可运行，外部 YAML 仅为可选覆盖 | 分发部署极简 |

## 3. 八境功法速查表

修炼体系将爬虫能力分为八个境界，从基础到终极逐层递进。

| 境界 | 功法名 | 类名 | 防御等级 | 核心能力 | 适用场景 |
|------|--------|------|:--------:|----------|----------|
| 0 | **源天书** | `YuanTianShu` | — | 基础 HTTP 请求（GET/POST）、URL 修复、标题清洗、线程安全 Session | 基类，不直接使用 |
| 1 | **轮海秘境** | `LunHai_BiAn` | 0 | 轻量直取：搜索→分类→详情→播放→首页，五接口齐全 | 无反爬的简单站点 |
| 2 | **道宫秘境** | `DaoGong_ShenZang` | 1 | 反爬防御：完整 HTTP 代理服务器、m3u8 广告过滤、Referer 伪装、随机延迟、失败重试 | 有防盗链/广告的站点 |
| 3 | **四极秘境** | `SiJi_TongTian` | 2 | 加密破解：AES-CBC / XOR / Base64 / Token 签名生成 | 有 JS 加密的站点 |
| 4 | **化龙秘境** | `HuaLong_JiuBian` | 3 | 全能混合：视频/小说/图片/漫画/音频/直播/综艺/动漫/Mix 九种协议自动分发 | 内容类型混合站点 |
| 5 | **仙台秘境** | `XianTai_DiJiuTian` | 4 | 大帝级整合：内部 RealmAutoRouter 自动降级选择最优子境界策略 | 复杂站点，自动适配 |
| 6 | **红尘仙** | `HongChenXian` / `Spider` | — | 万法归一：TVBox 标准入口，一键自动路由 | 生产和最终入口 |
| 7 | **洞天境** | `DongTian_HengYu` | 4 | 现代 HTMX / SPA / CloudFlare 抗压：HX 伪头部、initPlayer m3u8 提取、episodeList 选集 | 现代抗压影视站（空壳首页 / 异步渲染 / CF 拦截） |

### 轮海四小境

| 小境 | 类名 | 能力 |
|------|------|------|
| 苦海 | `LunHai_KuHai` | 仅实现 searchContent |

| 神桥 | `LunHai_ShenQiao` | + detailContent |
| 彼岸 | `LunHai_BiAn` | + homeContent + playerContent（五接口圆满） |

```
JieJingBase (抽象基类)

       ├─ DaoGong_ShenZang (道宫·五脏神藏)
       ├─ SiJi_TongTian (四极·四肢通天)
       ├─ DongTian_HengYu (洞天境·横宇)   # 现代 HTMX / CloudFlare 站点
       ├─ HuaLong_JiuBian (化龙·九变登仙)

       │         └─ XianTai_DiJiuTian (仙台·大帝)
```

## 6. 快速开始

### 6.1 编程用法

```python
# 导入
from zhetian_fa import create_spider_for, ZheTianLogger, stats

# 一行代码自动路由
spider = create_spider_for("https://example-video.com")

# 调用 TVBox 标准接口
home = spider.homeContent()
category = spider.categoryContent(tid="1", pg="1", filter=False, extend={})
detail = spider.detailContent(["123"])
play = spider.playerContent(flag="ikang", id="123", vipFlags="")
search = spider.searchContent(key="斗罗大陆", quick="1", pg="1")

# 查看统计
print(stats.report())
```

```python
spider = LunHai_BiAn()        # 轻量直取，站点无反爬
```

```python
router = RealmAutoRouter()

# 仅分析，不实例化
analysis = router.analyze("https://example.com")

# 分析 + 实例化一步到位
spider = router.route("https://example.com")
# 返回: 对应境界的实例（LunHai_BiAn / DaoGong_ShenZang / ...）

# 查看已缓存的站点分析
```

### 7.3 TVBox 六接口（所有境界类通用）

| 接口 | 签名 | 说明 |

## 11. 洞天境专项（现代 HTMX / CloudFlare 站点）

> 本章是 2.1 的核心新增内容。**如果你要把遮天法分享出去、且目标站点是现代抗压站点，请重点读这一章。**

### 11.1 痛点：为什么老境界在 moovie 这类站点上"全是 DEMO"

老 MacCMS 站点是**服务端渲染（SSR）**的静态 DOM：你 `requests.get` 一次，HTML 里就有完整的 `<a>`、`<img>`、播放地址。轮海/化龙直接 BeautifulSoup 解析即可。

但 moovie.c2v2.com 这类现代站点是 **HTMX + 异步渲染（SPA）**：

1. 首次请求只返回一个**空壳**（loading 骨架），真正的列表/详情靠 `htmx.js` 局部刷新把 HTML 片段塞进 `<main>`；
2. 服务端靠 `HX-Request: true` 等**伪头部**区分"真人点击"和"直连爬虫"——你没带这些头，它就回空壳，于是你看到的全是 DEMO / 空数据；
3. 播放页 `/play/...` 反而**必须走普通 GET**（带 HX 头会直接 404）；真正的 m3u8 藏在页面 JS 的 `initPlayer('...','<m3u8>',{...})` 里，且斜杠被转义成 `\/`；
4. 剧集列表在播放页 JS 的 `episodeList = [{title,url}]` 数组里，不再是 `<a>` 标签。

`RealmAutoRouter` 原来的 24 项特征对这种站点**完全盲区**——它把"空壳首页"误判成"无反爬的轮海境"，然后 Beautifulsoup 在一堆空 `div` 上解析，自然一无所获。

### 11.2 路由：三大现代特征命中即入洞天境

`FEATURE_SCANNERS` 新增三项（特征总数 24 → 30）：

| 特征 | 命中即说明 |
|------|-----------|
| `modern_htmx` | 站点用 HTMX 局部刷新（htmx.min.js / HX-Request / hx-get / data-hx- / hx-target / hx-swap） |
| `modern_cloudflare` | 被 CloudFlare 接管（__cf_bm / cf-ray / challenge-platform / cdn-cgi / cloudflare） |
| `modern_async_shell` | 异步空壳（id="app" / id="root" / __NEXT_DATA__ / 骨架屏 / data-server-rendered） |

`analyze()` 中：**三项任一命中 → 直接判定为「洞天境」**（防御等级封顶 4），不再套用旧等级体系。`route()` 实例化 `DongTian_HengYu`。

```python
router = RealmAutoRouter()
rep = router.analyze("https://moovie.c2v2.com")   # realm == "洞天", modern == True
spider = router.route("https://moovie.c2v2.com")  # <class 'DongTian_HengYu'>
```

### 11.3 DongTian_HengYu 内部机制

| 接口 | 做法 |
|------|------|
| `homeContent` | 返回 4 个分类（电影/电视剧/综艺/动漫 → movie/tv/show/cartoon），可按站微调 `DISCOVER_TYPES` |

### 11.4 CloudFlare 终极拦截：curl_cffi

若站点用 CloudFlare 的 **TLS 指纹 / Bot 管理**（不是简单 5 秒盾），普通 `requests` 会被拦。洞天境支持 `curl_cffi` 浏览器指纹伪装：

```python
class DongTian_HengYu(YuanTianShu):
    USE_CFFI = True   # 置 True 后所有请求走 curl_cffi.impersonate="chrome131"

# 首次需安装：
# pip install curl_cffi
```

> **重要**：`USE_CFFI=True` 但环境**未安装 curl_cffi** 时，框架会**显式抛出 RuntimeError 并提示安装命令**，而不是像旧版那样静默 `return ""`——静默降级只会让你拿到空页面，问题更难排查。

### 11.5 换站适配：只改配置，不改逻辑

`DEFAULT_CONFIG["洞天"]` 与 `realm_config.yaml` 的 `洞天` 段暴露了所有可调旋钮：

```yaml
洞天:
  htmx:
    headers: { HX-Request: "true", HX-Target: "main", HX-Current-URL: "{siteUrl}/" }
    content_api_use_htmx: true          # 列表/搜索/详情走 HTMX；播放页永远是 false
  endpoints:
    discover: "/discover/{type}"        # 路径式（优先）
    search:   "/api/htmx/search?kw={kw}"
    play:     "/play/{src}/{vod}?douban_id="
  regex:
    episode_list: 'episodeList\s*=\s*(\[.*?\]);'              # 剧集数组
    init_player:  'initPlayer\(\s*'\''[^'\'']*'\''\s*,\s*'\''([^'\'']+)'\''\s*,'  # m3u8
```

如果目标站点的端点或字段名不同（比如 `epList` 而不是 `episodeList`），只改这里的 `regex` / `endpoints` 即可，洞天境的解析逻辑无需重写。`DongTian_HengYu` 里的类常量（`DISCOVER_TYPES` / `DISCOVER_PATH` / `SEARCH_ENDPOINT` 等）也都能直接覆盖。

### 11.6 排错清单

| 现象 | 原因 | 解决 |
|------|------|------|
| 全是 DEMO / 空列表 | 没带 HX 头，拿到空壳 | 确认路由进了洞天境；分类/搜索接口被 `htmx=True` 覆盖 |
