## 四、方法论：spider-craft 六步队形

```
1. 站点探测 → 2. 请求层 → 3. 数据提取 → 4. 解密/编码 → 5. 播放处理 → 6. 代码生成
```

**每步要点**：
1. **探测**：识别 CMS（苹果/海螺/自定义 API/SPA）、反爬（CF/WAF/验证码）、数据来源（HTML/JSON/JS变量/iframe）、加密（base64/AES/混淆）
2. **请求**：四层降级 `requests → cloudscraper → curl_cffi(impersonate='chrome124') → requests`
3. **提取**：vod_id/vod_name/vod_pic/vod_remarks，详情页标题/演员/简介，剧集线路
4. **解密**：base64 → AES-CBC(key,iv) → PKCS7 → utf-8；图片魔数判断
5. **播放**：直链 m3u8/mp4（parse=0）或解析页（parse=1）；加密流走 localProxy
6. **生成**：裸类 Spider，全套契约方法，返回 dict 规范

**5 类站点模板**（`skills/spider-craft/SKILL.md`）：
- 类型A 苹果CMS：`/vodtype/{id}.html` + `/voddetail/{id}.html` + player_aaaa.url
- 类型B 海螺：`/xq/{id}.html` + `/bf/{id}-{sid}-{nid}.html` + data-original
- 类型C 自定义 API：JSON 接口，可能 encData/base64/AES
- 类型D 资源下载站：磁力/网盘链接
- 类型E SPA：AJAX 加载，找 API 端点（或浏览器渲染，不适合 TVBox）

## 五、TVBox Spider 契约规范（生成代码必须遵守）

### 6.1 方法签名

```python
class Spider:  # 裸类，不继承（T4 运行时除外）
    def getName(self) -> str
    def init(self, extend='')            # extend 可传 token
    def homeContent(self, filter)        # 返回分类+首页
    def homeVideoContent(self)           # 首页视频
    def categoryContent(self, tid, pg, filter, extend)
    def detailContent(self, ids)         # ★ ids 可能是 list/tuple！
    def searchContent(self, key, quick, pg)
    def playerContent(self, flag, id, vipFlags)
    def localProxy(self, param)          # 本地代理
    def isVideoFormat(self, url) / manualVideoCheck / destroy / action
```

### 6.2 返回格式

- 分类：`{"class": [{"type_id","type_name"}], "filters": {}}`
- 列表：`{"list": [{"vod_id","vod_name","vod_pic","vod_remarks"}], "page", "pagecount", "limit", "total"}`
- 详情：`{"list": [{"vod_id","vod_name","vod_pic","vod_play_from","vod_play_url",...}]}`
- 播放：`{"parse": 0, "url": "...", "header": {"User-Agent": "...", "Referer": "..."}}`（header 必须是 dict）
- 分隔符：`$$$` 多线路 / `#` 集数 / `$` 集名与地址
- localProxy 返回 `[200, mime, body_bytes]`

### 6.3 ★ 关键坑（写 Spider 必查）

1. **detailContent 的 ids 是 list/tuple**（不是字符串）！必须开头归一化：
   ```python
   if isinstance(ids, (list, tuple)):
       ids = ",".join(str(i) for i in ids)
   ids = [i.strip() for i in str(ids).split(",") if i.strip()]
   ```
   沙箱手测用字符串测不出此坑，必须补列表/元组用例。
2. **SPA 站点的播放拼接逻辑在懒加载 chunk**（不在主入口 JS）——顺着 import 关系定位小 chunk。
3. **API 参数不能靠猜**：从官网实际请求 body 解密确认（如糖心 UP主视频参数是 `home_id` 不是 `user_id`）。
4. **header 必须是 dict**，localProxy 返回四元组 `[status, mime, body]`。
5. 空 ID 不崩溃、超时降级、404 不崩溃、无 requests 用 urllib 兜底。

## 九、破站工作流程（新 AI 操作手册）

```
STEP 1 探测：curl -sI 目标URL → 看 Server/Content-Type；curl -s 首页HTML → 判断 CMS/SPA/反爬
STEP 2 抓 JS：SPA 站抓入口 JS（/assets/index-*.js）→ grep API 端点 + 加密关键词
STEP 3 测 API：curl 各端点 → 游客可访问？需要 token？返回格式？（JSON/HTML/加密）
STEP 4 破播放：videoUrl 拼接逻辑（可能在懒加载 chunk，顺 import 找）
STEP 5 生成 Spider：按第六节契约，兼容 ids list/tuple，编译 + 沙箱自测
STEP 6 交付：文件 + 说明 → 用户加载到空壳验证
STEP 7 回写：经验存入 field-journal / 更新本文档
```

### 1.1 固定 key AES-CBC（最基础）

### 1.2 请求参数加密 + 响应 KDF 动态密钥（劳动站）
```python
# 响应：base64 → salt(12字节) + AES-CBC 密文
# KDF：key = f(interfaceKey + salt) 多轮 sha256 分片组合派生 key/iv
def _dec_resp(data_b64):
    raw = base64.b64decode(data_b64)
    salt = raw[:12]
    r = ik.encode() + salt
    k1 = sha256(r); s = k1[8:24]
    key = sha256(s + r[:len(r)//2])[:8] + sha256(r[len(r)//2:] + s)[8:24] + ...
    # AES-CBC 解密 raw[12:]
```

### 1.3 gzip + AES + 动态 HMAC key + 随机 IV（黄豆短剧，最完整）
```python
# key 动态生成：hmac(platform_key, requestId)

# 请求体：随机 iv + AES-CBC(gzip(json), key, iv)

# 响应解密：判断 gzip 魔数 \x1f\x8b 解压
```

**关键识别**：响应头/体出现 `\x1f\x8b`（gzip 魔数）+ 16 字节对齐 → gzip+AES 组合。

### 1.4 图片 XOR 解密（通用 key）
```python
# 前 N 字节 XOR 固定 key（key='2020-zq3-888' 在多站出现：madouai/推特APP 通用）
def _img_decode(data, length, key):
    if data[:3] in (b'GIF', b'\xff\xd8\xff') or data[1:8]==b'PNG\r\n\x1a\n':
        return data  # 已明文，跳过
    arr = bytearray(data)
    for i in range(min(length, len(arr))): arr[i] ^= key[i % len(key)]
    return bytes(arr)
```

#### 九、Next.js RSC 站破法（XXAV 实战经验）

> 来源：实战破 xxav2295.sbs（Next.js App Router + Cloudflare + HLS）

**特征**：`x-powered-by: Next.js` + `self.__next_f`（RSC flight payload）+ Turbopack chunk。

**破法**：
1. **别在 JS chunk 里找 API**——RSC 模式数据在服务端，客户端 JS 只有框架代码，搜不到端点
2. **用 browser_use 观察实际请求**——导航/点击后看 `performance.getEntriesByType('resource')` 里的 `/api/` 请求
3. **独立 JSON API 通常存在**——Next.js 除了 RSC 还有 `/api/*` 路由，直接 curl 测（无签名就直接能用）

**XXAV 完整契约**（示例）：
```
分类  /api/navCategory → data[]（pid=0 顶级）
列表  /api/filmClassifySearch?Pid={tid}&current={pg} → data.list
详情  /api/filmPlayInfo?id={vid}&playFrom=0&episode=0 → data.detail + data.current.link(m3u8)
首页  /api/index → data.content[].hot[]（注意字段大写 ID）
播放  m3u8 相对路径 → 拼域名（HLS master）
```

**两个坑**：
- 分类器检测到 sign 关键词 ≠ 真有签名，**curl 打端点看是否 401/403 才是铁证**
- 同一站不同接口字段大小写可能不一致（首页大写 ID、列表小写 id），分别实测

### 10.y TVBox / FongMi Spider 坑位（P0-P8）

> 来源：GitHub 项目 [jiusanzhou/site2source](https://github.com/jiusanzhou/site2source)（声明式站点→TVBox源生成器）
> 提炼其 `spider-pitfalls.md` 的 8 个血泪坑 + QuickJS 环境限制。按严重度排序，写/调试 Spider 时对照查。

#### 🔴 P0 · tvbox.json 的 `flags` 数组不能含 site 自家 key

- **症状**：FongMi/TVBox 点站源弹 `Unable to parse url` toast，什么都拉不出来
- **原因**：FongMi 用 `flags` 做 spider 分类映射，写 `["站点名"]` 会让客户端 `parseUrl("站点名")` → 非法 URL → crash
- **修复**：flags 只放通用能力标签（如 `["b"]`），或留空

#### 🔴 P1 · `type` 字段用错

| type | 含义 |
|------|------|
| 0 | MacCMS 采集站（api 字段填 XML 采集 URL） |
| 1 | MacCMS v10 JSON 采集 |
| **3** | **Drpy JS spider**（生成的 JS 源用这个） |
| **4** | **Drpy Python spider** |

用 0/1 会让 FongMi 按 MacCMS 协议解析 → 白屏。

#### 🔴 P2 · vod_play_url 里 flag 名重复导致选集塌陷

FongMi 用 `flag$url#flag$url...` 格式，但 **flag 名不能全相同**：
- **错**：`hls$url1#hls$url2#hls$url3` → 只显示第一集
- **对**：`第1集$url1#第2集$url2#第3集$url3`

ep 名候选顺序 `["name","title","episode"]`，别用重复的 flag 名。

#### 🔴 P3 · 签名公式顺序错

签名拼接顺序不能靠猜。**至少抓 3 个不同时间戳的请求反向验证**，或用签名验证器工具确认公式顺序。

#### 🔴 P4 · query 参数被大小写洗过

很多签名算法用 `query_lower`（整条 query 转小写后拼签）。本地拼签要跟服务端一致，统一用小写处理。

#### 🔴 P5 · 分页策略选错

- `server`：服务端支持 `page` 参数
- `local`：一次拉大 size 本地切片（服务端"分页"是假象时用）
- `none`：服务端一次给全

选错表现：翻页空 / 重复项 / 500。

#### 🔴 P6 · GEO block 认成签名错

- **症状**：curl 打端点返回 HTML 而非 JSON，body 含 `error code: 1009`，日志 `Unexpected token '<'`
- **原因**：Cloudflare 拒特定地区 IP，跟签名/参数无关
- **修复**：挂 cf-proxy（见 cf-bypass 技能）

#### 🔴 P7 · bootstrap 提取的 key 类型不稳定

配置里的 key 有时是字符串 `"abc"`、有时是数组 `["abc","def"]`。拼签名时炸。需统一转数组再取 `[0]`。

#### 🔴 P8 · 播放地址挑到广告 CDN

能出播放地址但播的是 30 秒广告 loop。原因：广告 CDN 塞在播放地址数组首位。需排除（host_regex 或 contains `/ads/`）。

## 十一、通用破甲经验库（踩过的坑）

1. **minify SPA 站**：播放/图片拼接逻辑在懒加载 chunk（如 468 字节的 videoPlayback），先看 import 关系定位 chunk。
2. **sign/base64 关键词是噪音**：signal/design/assign 都含 "sign"，要精确匹配排除框架代码。
3. **Nuxt 站密钥暴露**：`env:{AES_KEY_HTTP:...}` 明文注入客户端 JS，密钥直接静态提取。
4. **风控 SDK 密钥硬编码**：AES-GCM 密钥硬编码在前端 JS，可静态提取。
5. **token 短时效 + 频率风控**：频繁请求触发限流，用"新鲜度 + 预刷新 + 退避"应对。
6. **API 参数靠逆向确认**：从官网实际请求 body 解密，不要猜参数名。
7. **HEAD 401 ≠ GET 失败**：nginx 可能禁 HEAD，GET 正常。
8. **TVBox 运行时差异**：沙箱测不出的坑（ids 类型），必须按壳的实际调用方式测。
9. **browser_use hook 网络**：SPA 站页面级 API 用浏览器 hook XHR/fetch + 滚动触发 + 解密 body 是最可靠的方法。
10. **URL 编码处理**：m3u8 代理 path 参数要 urlencode（含路径分隔符）。
