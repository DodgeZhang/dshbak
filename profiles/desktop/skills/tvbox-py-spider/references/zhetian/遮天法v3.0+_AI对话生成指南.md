## 1. 框架概述

遮天法是一套面向 **TVBox / 影视仓 / py-drpy / drpy-node** 生态的爬虫源开发框架。

以《遮天》修炼体系为隐喻，将爬虫技术映射为"九秘→极道帝兵"和"八境功法"。

### 核心设计理念

| 原则 | 说明 |
|------|------|
| **配置驱动** | 适配新站只需改 `DEFAULT_CONFIG`，零代码 |
| **九秘独立** | 九种能力解耦为可独立调用的工具类 |
| **优雅降级** | 缺失依赖不崩溃，功能受限但框架可用 |
| **全 try-except 兜底** | 任何错误都不应导致整个爬虫崩溃 |
| **防递归设计** | 仙台境自动路由避免自我引用 |
| **零歧义代码** | 字符串引号、括号闭合、类型标注100%正确 |

## 5. AI 生成代码的绝对铁律 ⭐⭐⭐

> **以下规则优先级高于一切。AI 在生成或修改遮天法代码时，必须逐条检查。**

### 铁律 1: 引号闭合检查

每写完一个包含 `"` 的字符串，立即做以下检查：

```python
# 错误示例（v3.0 原始）:
"sec-ch-ua": "\"Chromium\";v=\"129\", "Not=A?Brand\";v=\"8\"",
# 数一下: 开头 " → 1, \" → 转义不算, \" → 转义不算, "Not → 2（闭合了！）

# 正确写法:
"sec-ch-ua": "\"Chromium\";v=\"129\", "Not=A?Brand\";v=\"8\"",
# 数一下: 开头 " → 1, 所有内部 " 都有 \ 转义 → 直到最后的 " → 2（正确闭合）
```

**AI 自检口诀**: `"` 出现偶数次（转义的 `\"` 不算），行尾必须是 `"` 或 `",`。

### 铁律 2: 括号闭合检查

每写完一个 `def` / `class` / `if` / `for` / `return` / `f"..."`，立即检查：

```python
# 错误示例:
return f"http://127.0.0.1:{cls._port}/{quote(url, safe='')}
# 缺少: "}  → 应该是: "}

# 检查方法:
# 1. 数 `{` 和 `}` 是否相等
# 2. 数 `(` 和 `)` 是否相等
# 3. 数 `[` 和 `]` 是否相等
# 4. 数 `"` 是否成对（转义的不算）
```

### 铁律 3: 防递归设计

任何涉及"自动路由"或"自动选择策略"的代码，必须包含防递归机制：

```python
# 必须这样写:
def route(self, url: str):
    analysis = self.analyze(url)
    realm = analysis["realm"]
    # 防递归：如果目标境界是自身，强制降级
    if realm == "仙台" and hasattr(self, '_routing_depth'):
        self._routing_depth += 1
        if self._routing_depth > 2:
            realm = "化龙"  # 强制降级
    return self._instantiate(realm, url)
```

### 铁律 4: 模块 vs 对象区分

```python
# 错误（v3.0 原始）:
import curl_cffi.requests as cffi_requests
session = cffi_requests  # 这是模块！
session.get(...)  # AttributeError

# 正确:
import curl_cffi.requests as cffi_requests
cffi_requests.get(...)  # 模块直接调用
# 或者:
from curl_cffi import requests as cffi_requests
cffi_requests.get(...)
```

### 铁律 5: 配置优先于硬编码

```python
# 禁止:
API_HOME = "/api.php/web/index/home"

# 必须:
endpoints = self.config.get("endpoints", default={})
home_path = endpoints.get("home", "index/home")
api_base = self.config.get("api_base", default="/api/")
```

### 铁律 6: 参数必须使用

```python
# 禁止: 声明了参数但函数体内完全不使用
def func(self, tid, pg, filter, extend):
    params = {"page": pg}  # tid/filter/extend 完全未使用

# 必须: 每个参数都有意义，未使用的要注释说明
def func(self, tid: str, pg: str, filter: bool, extend: Dict):
    params = {"page": pg, "type": tid}
    if filter and extend:
        params.update(extend)
```

### 铁律 7: 异常分级处理

```python
# 禁止: 所有异常一锅端
try:
    ...
except Exception:
    pass

# 必须: 分级处理
try:
    r = self._get_session().get(url, timeout=15)
    r.raise_for_status()
    data = r.json()
except requests.Timeout:
    self.log.warning(self.realm_name, "请求超时")
    return None
except requests.HTTPError as e:
    self.log.error(self.realm_name, f"HTTP错误: {e.response.status_code}")
    return None
except json.JSONDecodeError:
    self.log.error(self.realm_name, "JSON解析失败")
    return None
except Exception as e:
    self.log.error(self.realm_name, f"未预期错误: {e}")
    return None
```

> **注意**: 追影_遮天法中的 `isVideoFormat` 使用列表推导式 `any(ext in url.lower() for ext in video_exts)`，
> 比 v3.1 原始代码中的 `".m3u8" in url or ".mp4" in url or ".mpd" in url` 更优雅、更易扩展。
> AI 生成时必须采用列表推导式版本。

## 13. 洞天境专项

### 13.1 痛点：为什么老境界在现代站点上"全是 DEMO"

现代站点使用 **HTMX + 异步渲染**：
1. 首次请求返回空壳（loading骨架）
2. 真实内容靠 `HX-Request: true` 等伪头部触发
3. 播放页 `/play/...` 必须走普通 GET（带 HX 头会 404）
4. m3u8 藏在 `initPlayer()` 中，斜杠转义为 `\/` 
5. 剧集列表在 `episodeList = [{title,url}]` 数组中

### 13.2 路由：现代特征命中即入洞天境

```python
# 三大现代特征任一命中 → 洞天境
modern_features = ["modern_htmx", "modern_cloudflare", "modern_async_shell"]
```

### 13.3 DongTian_HengYu 关键机制

| 接口 | 做法 |
|------|------|
| `homeContent` | 返回 4 个分类（movie/tv/show/cartoon） |
| `categoryContent` | `GET /discover/{type}`，带 HX 伪头部；失败 fallback 到 `?type=` |
| `searchContent` | `GET /api/htmx/search?kw={kw}`，带 HX 伪头部 |
| `detailContent` | 普通 GET 播放页，从 `episodeList` 抠剧集 |
| `playerContent` | 普通 GET 播放页，从 `initPlayer()` 抠 m3u8，`\/` → `/` |

### 13.4 curl_cffi 使用

```python
class DongTian_HengYu(JieJingBase):
    USE_CFFI = True   # 需要: pip install curl_cffi

    def _fetch(self, url, headers=None, timeout=10, htmx=False):
        h = self._build_headers(headers)
        if htmx:
            h.update({"HX-Request": "true", "HX-Target": "main"})
        if self.USE_CFFI and HAS_CFFI:
            return cffi_requests.get(url, headers=h, timeout=timeout, impersonate="chrome131")
        return self._get_session().get(url, headers=h, timeout=timeout)
```

> **重要**: `USE_CFFI=True` 但未安装时，**显式抛出 RuntimeError**，不静默降级。

## 14. 九秘核心能力库详解

### 14.1 BingZiMi（兵字秘）

**核心算法：**
- AES-CBC：支持 hex/base64/raw 输入，自动 MD5 补齐密钥到 16 字节
- XOR：前 N 字节异或解密，常用于图片/视频流
- Base64：兼容标准和 URL-safe
- 多层组合：链式调用 `multi_layer_decrypt(data, ["base64", "url", "hex"])`

### 14.2 DouZiMi（斗字秘）

**核心算法：**
- 净化术：`re.sub(r"<[^>]+>", "", text)` → `html.unescape()` → 去空白
- 修图术：自动补全协议 `//` → `https:`，补全域名，代理转换
- 七十二变：BS4 第一层 → 正则三层回退

### 14.3 ZheZiMi（者字秘）

**核心算法：**
- safe_call：函数级 try-catch，错误返回 None
- safe_get：支持点号路径 `"data.list.0.title"`
- retry_with_backoff：`delay = backoff_factor * (2 ** attempt)`

### 14.4 JieZiMi（皆字秘）

**核心算法：**
1. 分段解析：header + segments（tags + uri + duration）
2. 主路径统计：按 `(域名, 目录)` 聚类
3. 三重过滤：关键词 + 短时长 + 前 N 段非主路径
4. 序列号重写：`#EXT-X-MEDIA-SEQUENCE = 原序列号 + 移除数量`

### 14.5 ZhenZiMi（阵字秘）

**核心算法：**
- 端口竞用：9979 → fallback_ports 列表自动尝试
- 请求转发：`http://127.0.0.1:port/<url>` → 解码 URL → 带 Referer/UA 请求
- XOR 解密：前 N 字节异或
- 线程安全：`ThreadingMixIn`

### 14.6 NiZiMi（逆字秘）

**核心算法：**
- Protobuf varint 编码/解码
- Wire type 0(varint)/2(length-delimited)/5(32-bit)/1(64-bit) 支持
- SHA-256/MD5 签名：按字母序排序参数 + secret_key
- WASM 风格请求构建：`build_decode_request(url, flag, finger, app_id, sk)`
