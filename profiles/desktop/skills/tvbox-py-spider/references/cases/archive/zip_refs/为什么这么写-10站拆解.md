# XBPQ 规则"为什么这么写"——10站深度拆解

> 用户 2026-08-11 要求：从 126 个实战规则中挑 10 个，逐段分析设计意图。
> 这份文档是理解用户写规则思维的钥匙，写新规则前先读一遍。

## 1. 每日大赛（动态域名 3 步工具链 + AES 图片 + 22 分类）

```json
"作者": "hxcnmlgb[工具:随机字符-3]",
"后缀": "https://www.rzvgofest.cc/[工具:源码#Base64.decode('截取')#解b64#words.random() + '.截取'∬words.random()+'.截取']",
"域名-c": "https://{{作者}}.{{后缀}}/",
```

- `源码` → 抓发布页；`Base64.decode('截取')` → 抠出括号内密文；`解b64` → 解码；`words.random() + '.截取'` → 抠真实后缀
- `∬` = 或（候选）：第一种截取失败用第二种（发布站可能改 JS 写法）
- 作者名 = 固定前缀 + `[工具:随机字符-3]` 随机防封
- 图片 AES：`{{前缀}}+loadBannerDirect('&&'[工具:源码转b64#解密aes-f5d965df75336270-97b60394abc2fbe1-AES/CBC/PKCS7Padding]`
- 播放锚点：`"mutex":true,*"video":{"url":"&&"`（mutex 定位 + * 跳过中间字段）

## 2. 51吃瓜（同款模板 + 备用域名 + 筛选面板）

- 和每日大赛同 CMS（WordPress），数组/图片/播放结构几乎一样 → 换分类+域名即可通用
- 多 `备用` 字段（被墙更狠，发布页失效直接切备用）
- **后缀工具链细节不同**：`Base64.decode('截取'))` 多一个 `)`，`words.random()*'.截取'` 用 `*` 不是 `+` → 必须匹配源码原文
- `类型` 字段 16 组 `||` 分隔 = 每个分类独立的筛选面板（`空||` 表示第一分类无筛选）

## 3. 91jav（GitLab 发布页 + 10 标签二级目录 + 分割）

- 发布页用 `gitlab.com/91JAV2/dz`（GitLab 域名难被墙）
- 后缀最简：`[工具:源码#words.random() + "截取"]`（明文直接抠，无 Base64）
- 作者 `[工具:1截取3]`：从"hxc免费分享"截前3字符 = 防改作者名
- 二级目录 10 个标签（女优阅兵式/衣着/身材/交合/玩法/剧情/角色/地点/杂项/番号），数组 13 组 `||` 各自指定
- `分割(前:<div class="col-6 col-sm-4 col-lg-3 mb-3">)`：同页多区域切分
- 特殊分类链接 `{顺序|month}` 自定义筛选
- 播放：`var hlsUrl*=*"&&"`；图片 z-image-loader（不是 loadBannerDirect）

## 4. 色最色（静态域名 + 苹果CMS + CDN 替换）

- 域名稳定 → 主页url 直接写死 jise7.com（发布页 helpfindgoodsite.com 兜底）
- 数组锚点长且唯一：`class="col-md-2 col-sm-3 col-xs-6 vod">&&<h4 class="title">`（防匹配导航/广告）
- 播放：`cms_player={*"len":null,"url":"&&"`（必须从对象起点 `{*` 开始，只写 `"url"` 会错位）
- `[替换:t26.>>t33.#t27.>>t33.#t30.>>t33.]` CDN 多域名统一替换
- `直接播放:1` + 分类url `;;z` 跳过详情页直接播

## 5. 1AV（27 分类 + 女优大全二级目录）

- 静态域名，27 个分类全列
- 二级目录"女优大全"：`folder-0-0-H` + 特殊分类链接 `vodtype/29.html`
- 女优大全页结构不同 → `女优大全--<a hr&&a>` 单独指定
- 播放 `"},\"url\":\"&&\"`（JSON 里抠 url）+ 嗅探

## 6. eporner（48KB 国际大站）

- 48KB = 完整筛选面板（画质/时长/日期/排序）+ 演员库
- 站本身 API 友好，结构简单，只是枚举量大
- 作者名可以随意（"屌戳插操"），站名可玩梗（"日你底下"）——XBPQ 不校验

## 7. 404（GitHub Pages 发布页 + 18 资源二级目录）

- 发布页 `404xav.github.io/url8/`（GitHub 难被墙），后跟 4 个备用
- 域名防封思路不同：`{{主页url-c}}[替换:https://>>https://666.]` 加前缀而非拼后缀
- 18 个二级目录 = 18 个资源站，每个特殊分类链接独立

## 8. 海角网（第一页无页码的中括号语法 + 发布页变量）

- `分类url: {{域名-c}}{cateId}/{catePg}/[{{域名-c}}{cateId}/]`：中括号=第一页 URL（无页码）
- 特殊分类链接 `&` 分隔（不是 `#`）：`海角首页$...&海角热门&...`
- 后缀用 `{{发布页}}` 变量引用（发布页多时更稳）

## 9. 黑料不打烊（words.random()*+ 变体）

- `words.random()*+"截取"` 乘号加号连写 —— 每个站 JS 写法不同，必须看源码
- 图片 `<img z-image-loader-url=` 带 img 前缀（91jav 不带）→ 前端代码差异
- 数组 `<meta itemprop="dateModified"&&</article>` WordPress 模板特征
- 直接播放留空 → 走嗅探

## 10. 好色tv（最简规则）

- 域名稳定 → 域名-c 直接写死，无发布页
- 播放 `<source id="&&"` HTML5 标签
- 特殊分类：最新/最热/周榜 只是 sort 参数不同
- 分类url `{cateId}-{cateId}` 照抄站点的怪异 URL 格式

## 核心方法论（10 站总结）

1. **先看源码再写规则**——每个站 JS 写法不同（`+`/`*`/`*+`/`∬`），截取必须匹配原文
2. **同模板站复用**——WordPress 模板（51吃瓜/每日大赛/黑料不打烊）数组几乎一样；苹果CMS（色最色）cms_player 通用
3. **动态域名 3 种思路**：拼后缀（作者+后缀）、加前缀（替换 https://）、发布页变量（{{发布页}}）
4. **防封组合拳**：发布页多备选 + 备用域名 + 随机前缀 + GitHub Pages 发布页
5. **二级目录**解决特殊页面（女优大全/标签云/资源站聚合）
6. **`||` 分类指定**是常态（85% 规则在用）——页面结构不同就单独写
7. **能简则简**：域名稳定就不搞动态，页面简单就短锚点
8. **兜底双保险**：∬ 候选、播放数组 || 备用区块、备用域名
