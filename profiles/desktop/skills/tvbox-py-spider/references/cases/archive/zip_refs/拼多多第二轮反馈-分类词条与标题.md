# 拼多多.py 教训补遗（2026-08-24 第二轮，json 转 py 交付后多轮反馈）

第一轮教训（data-preview 直链站结构/播放链接替换/羊壳没数据三根因/翻页字段）见 `references/羊壳py没数据排障清单.md` 与 `references/拼多多-data-preview直链站.md`。本文件记录用户第二轮反馈的四个修正点。

## 1. 所有类型 ≠ 所有标签（json"数组"字段按分类指定）

用户反馈"所有类型和所有标签怎么是一样的？你看下json文件"——我第一版把两个 folder 都解析成了 fenlei 列表。json 的 `数组` 字段为每个分类单独指定截取区：

- **所有类型** → `?categories={catePg}.html` 页面，数组区 `<div class="collapse show">&&<div class="content__button">`，分割前 `<div class="models-wost__col">`，**36 个分类带图**（ic-img.usite.pro/categories/*.jpg），标题 `<center>&&</center>`，链接 `/?fenlei={分类名}` → folder 项 `dir_fenlei:{名}`
- **所有标签** → `?tags-ch-all.html` 页面，数组区 `<center>&&</center>`，分割前 `<a class="buttons black">`，**245 个标签**，标题 `title="&&"` 属性，链接 `/?tag={标签}` → folder 项 `dir_tag:{名}`

**教训：json 转 py 时逐分类对照 json 的数组/标题/链接字段（`||分类--规则` 段落），每个分类的截取锚点都不同，不要图省事统一用同一个解析函数抓 fenlei。**

## 2. 删掉吃屎喝尿分类

用户要求删除。json 分类 `所有视频#推荐类型#所有类型#推荐标签#所有标签#吃屎喝尿$吃屎喝尿#自定义词条$屎` 里吃屎喝尿是独立词条分类。用户第二轮明确"删掉吃屎喝尿"→ 从 self.classes 和 categoryContent 分支同时删（分类删除要同步清理路由分支，同 8度 删分类教训）。

## 3. 自定义词条默认打开第一个

用户反馈"词条默认打开第一个"。custom 分类无筛选参数时**不要返回空 list**，而是 `word = '丝袜'`（filters 第一个词条）直接搜索返回 28 条。用户打开"自定义词条"分类立即看到内容，而不是先弹筛选选择。

词条换新（用户"默认的那几个我不喜欢重换几个"）：先逐个 GET `?search={词条}&p=1` 验证 `data-preview` 计数 >0 再写进 filters。实测丝袜/黑丝/白丝/制服/护士/教师/空姐/口爆/颜射/自慰全 28 条。

## 4. 所有视频页标题是站点懒加载（无接口）——确认无法修复

用户三问"所有视频还是不显示名字"。彻底排查结论：

- 首页/标签页/搜索页的 `<p class="mb-1"><a href="...">标题</a></p>` **有标题**（服务端渲染）
- 所有视频页 `?video={pg}.html`、分类页 `?fenlei={名}` 的同一标签**为空**（`<a href="..."></a>`）——标题由 JS 懒加载填充
- 找接口：jiazai.js 只做 hover 预览（data-preview 加载 m3u8 视频），main.min.js 是 bootstrap，trku.js 是弹窗，`/ai/s/s/sum.php` 是统计；`?k=` 是搜索建议 JSON；`/?play-{id}-1-.html` 返回首页列表（无详情页概念）；`/?id={id}` 是 yzmplayer 播放页但 `config.title` 也是空
- **json 版在这些页显示的同样是数字 ID**——json 标题字段第二备选 `<p class="mb-1"><a href="/?play-&&-1-.html">` 就是截取 `play-` 和 `-1-` 之间的 ID

**结论：站点限制，向用户说明即可（"json 版同样显示 ID"），不要继续找接口浪费时间。**
