## 1. 发布页 appConfig 自动解密（get_working_host）

```python
entry_url = "https://www.qcoplglgu.com/"   # 发布页
pattern = r'window\.appConfig\s*=\s*\{[^}]*data\s*:\s*"([^"]+)"[^}]*key\s*:\s*"([^"]+)"'
matches = list(re.finditer(pattern, html, re.DOTALL))
last_match = matches[-1]                     # 取最后一个 match
enc_data, key_str = last_match.group(1), last_match.group(2)

raw = base64.b64decode(enc_data)
iv_bytes = raw[:16]                          # 🌟 IV = 密文前16字节（方案B！）
ciphertext_bytes = raw[16:]
aes_key = hashlib.sha256(key_str.encode("utf-8")).digest()  # 🌟 key = sha256 digest（非 hex）
cipher = AES.new(aes_key, AES.MODE_CBC, iv_bytes)
decrypted = cipher.decrypt(ciphertext_bytes)
try: decrypted = unpad(decrypted, AES.block_size)
except ValueError: pass                      # 失败保留原数据
config = json.loads(decrypted.decode("utf-8"))
# config["domain"] = [{"name":"线路一","value":"https://..."}], config["main"], config["backup_domain"]
```

**关键**：这套是**方案B**（IV=raw[:16]，key=sha256 digest）——与小男娘方案A（IV=sha256hex[:16]，key=bytes.fromhex）不同！两个方案都试。

**测活验证**：`len(data('#index article a')) > 0 or len(data('#archive article a')) > 0`（pyquery 结构特征）

## 4. 完整代理链（localProxy）

```python
def localProxy(self, param):
    if param.get('type') == 'img':
        res = requests.get(param['url'], ...)
        return [200, res.headers.get('Content-Type'), self.aesimg(res.content)]
    elif param.get('type') == 'm3u8':
        return self.m3Proxy(param['url'])    # m3u8 重写：相对路径补全 + KEY URI 代理
    else:
        return self.tsProxy(param['url'])    # ts 分片代理

def proxy(self, data, type='m3u8'):           # 只有配置了 proxies 才走代理
    if data and len(self.proxies):
        return f"{self.getProxyUrl()}&url={self.e64(data)}&type={type}"
    return data
```

- **m3Proxy**：m3u8 内容逐行重写——`#EXT` 行不动；非 http 相对路径补全（`string.count('/') < 2` 用 m3u8 目录，否则用 scheme://netloc）；`URI="..."` KEY 行包 proxy(mkey)；其他行 `self.proxy(string, ext)` 包 ts 代理
- **tsProxy**：b64 解 url → 流式下载 → 返回原 Content-Type
- **图片**：`getimg` 从 `loadBannerDirect('...')` 提取**明文 URL**（不 b64），直接 `getProxyUrl()&url=URL&type=img`；localProxy 下载内容 → aesimg 解密（key f5d965df75336270 / iv 97b60394abc2fbe1，unpad）
