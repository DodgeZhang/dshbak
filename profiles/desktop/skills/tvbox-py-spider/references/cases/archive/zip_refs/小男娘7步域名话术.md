## 7 步逻辑（用户原文精炼）

打开 https://nanniang10.com/ 的源码，需要的部分是 `data: "&&"` 和 `key: "&&"`（&& 为截取占位）。

1. **截取 key**：定位 `key: "0726001"`，截取 `0726001`
   → xbpq：`"key截取": "{{发布页}}[工具:源码#key:*\"截取\"]"`
2. **SHA 加密**：对 key 做 SHA，得 `424be22131024abd...a1a4e0`（hex），这就是 AES 的 key
   → xbpq：`"key": "{{key截取}}[工具:SHA]"`
3. **取 iv**：key hex 的前 16 位 = AES 的 iv
   → xbpq：`"iv": "{{key}}[工具:1截取16]"`
4. **截取密文**：源码里定位 `data: "&&"`，截取全部密文
5. **AES 解密 + 取后缀**：解密后定位 `"zz_line":"mgbywlre.com"`（备用 `"zz_backup_line":"ltkfgnizr.com"`），取值即后缀
   → xbpq：`"后缀": "{{发布页}}[工具:源码#data:*\"截取\"#解aes-{{key}}-{{iv}}-AES/CBC/PKCS7Padding#\"zz_line\":\"截取\"]"`（zz_backup_line 备用自动，勿动）
6. **随机前缀**：从 `abcdefghijklmnopqrstuvwxyz0123456789` 取不重复随机 5 字符
   → xbpq：`"作者": "abcdefghijklmnopqrstuvwxyz0123456789[工具:随机字符-5]"`
7. **拼域名**：`https://{{作者}}.{{后缀}}/`
   → xbpq：`"域名-c": "https://{{作者}}.{{后缀}}/"`

**关键细节：** `data: "&&"` 和 `key: "0726001"` 中冒号后可能有空格，xbpq 用 `*` 替代冒号后的空格（`key:*"截取"`、`data:*"截取"`）。

## 构建 py 源的补充提示（用户原文）

1. 男娘网和每日大赛使用**完全一致的图片解密**（AES key/iv 相同），男娘网图片位置是 `z-image-loader-url="`&&`"`（**反引号**包裹）
2. 男娘网有类似每日大赛标签云的二级结构：一级为分类列表，点进去二级为视频列表
3. xbpq 用了跳转播放链接：`"跳转播放链接": "<div class=\"dplayer\"**\"video\":{\"url\":\"&&\""`，py 中也可用
4. 首页/原创主/up主/up主收藏榜/标签都是二级结构，但定位和取值略有区别，参照 xbpq 的数组字段
5. 注意一级和二级的翻页，可参照链接
6. 注意搜索结构
