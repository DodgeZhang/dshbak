## 一、汽水音乐官方 API（免费歌曲主通道）

- 基址：`https://api.qishui.com`，Referer `https://music.douyin.com/`，UA 安卓（`Linux; Android 10; TVBox`）
- 响应可能 gzip：`res.headers.get("Content-Encoding","").lower()=="gzip"` → `gzip.decompress(raw)`
- 请求统一 `_request_json(url, data=None)`：data 有值 → POST + `Content-Type: application/json; charset=utf-8`

### 关键端点

| 端点 | 用途 |
|------|------|
| `/luna/feed/mode` | 听歌模式列表（POST `{"ab_param":"","feed_extra":None}`）→ `feed_mode_block[].feed_mode[]` 里 `entity.feed_scene_mode` 的 scene_mode_id/text/sub_queue_type |
| `/luna/discover` + `/luna/discover/mix` | 发现页（block/inner_block/resources） |
| `/luna/search/listen_video` | 听抖音视频搜索（`search_type=listen_video`，MD5 search_id） |
| `/luna/feed/radio/tracks` | 电台曲目（POST `{"radio_id":...,"flow_type":2,"full_media":True}`）→ items |
| `/luna/charts/{id}` | 榜单曲目 → chart.track_ranks/tracks |
| `/luna/playlist/detail` | 歌单曲目（POST playlist_id，count=100）→ media_resources |
| `/luna/search/track` | 歌曲搜索（`search_type=track`，MD5 search_id，cursor 分页）→ result_groups 里 id=="tracks" 的 data |
| `/luna/h5/seo_track?track_id=` | **单曲详情/播放源**（GET）→ `track_player.video_model`（可能是 JSON 字符串）+ `seo_track` + `lyric.content` |

### vod_id 打包协议（音乐源通用）

```python
_pack(kind, value)   -> kind + ":" + base64.urlsafe_b64encode(json.dumps(value)).decode().rstrip("=")
_unpack(value, kind) -> 前缀匹配 kind + ":" → base64url 解码（补 = 到 4 倍数）→ json.loads
# 三种 kind：
#   mode        {"id","name","kind":"preference|scene","sub"}   听歌模式
#   collection  {"id","kind":"radio|brief_chart|chart|playlist","name","desc","pic"}  合集
#   video       {"vid","video_id","name","pic","author","duration"}  听抖音短视频
# 歌曲播放 URL 内嵌在播放列表里： 歌曲名$a:{track_id}:{quality}
```

### playerContent

- `v:{vid}` → `https://aweme.snssdk.com/aweme/v1/play/?video_id={vid}&ratio=1080p&line=0`（抖音短视频）
- `a:{track_id}:{quality}` → `_audio_streams(_seo(track_id))` 选 quality（默认 auto=最高码率）
- 返回 `{"parse":0,"jx":0,"url":...,"music_player":1,"header":{"User-Agent":...,"Referer":"https://music.douyin.com/"}}`
- `music_player: 1` 是手机端专属音乐播放器标记；旧版/TV 端安全忽略
- `isVideoFormat` 返回 False

## 二、yx520 接口（VIP/试听歌曲替代，2026-08-19 实测）

域名 `www.yx520.ltd/API/`。**中文参数必须 `urllib.parse.quote`，直接拼 URL 报 `'ascii' codec can't encode`**。

### ① 酷我 kwyy（用户钦定主替代，返回完整 MP3 非试听）

```
GET http://www.yx520.ltd/API/kwyy/api.php?msg={歌名}&a=10&n=1
→ {"code":"200", "name":"1. 歌名---歌手\n2. ...", "url":"http://car-lv.kuwo.cn/.../M800...mp3"}
```
- `a=10` 音质参数（1/10 都返回 MP3 直链，10 为高音质档）；`n=1` 取搜索结果第 1 首
- url 实测 `200 audio/mpeg`，8.5MB 完整 MP3（头 ID3 + MPEG 帧 `\xff\xfb\xe0`）
- **注意**：url 是"搜索结果第 1 首"，歌名模糊时可能不是目标歌（搜"偏爱"返回"破天荒"）——可接受或后续加 n 参数轮询
- 播放需 UA，Referer 不强求

### ② 抖音 dyyy（备用）

```
GET http://www.yx520.ltd/API/dyyy/api.php?msg={歌名}
→ {"code":"0","msg":"ok","data":[{"title":"歌名---歌手","imgurl":"...douyinpic...","url":"https://v26-ktv.douyinvod.com/.../audio_mp4..."}]}
```
- 返回列表 5 首左右，**优先取 title 含搜索关键词的第一首**（`next((it for it in items if keyword in it["title"]), items[0])`）
- 播放 URL 带 Referer（如 `https://www.douyin.com/`）才 200；不带 Referer 我服务器 403
- url 是 `audio_mp4` 格式（抖音音频容器）

### ③ 替代顺序（用户定稿，2026-08-19 + 08-22 增补）

> 用户原话：付费的按照酷我的替换，不要你之前给我换那个接口了

- 免费歌 → 汽水官方 API（streams 非空）
- VIP/试听歌 → **酷我 kwyy 主 → 抖音 dyyy 备用 → iTunes Search 兜底**（2026-08-22 用户要求音乐融进去就行需要代理的不要写 后加 iTunes：`https://itunes.apple.com/search?term={歌名}&limit=1&media=music` → `results[0].previewUrl`，免密直连 30 秒 m4a 试听，最后兜底）
- 曾用 meting（`api.qijieya.cn/meting/?type=search&server=netease&limit=1&id=歌名`）被用户否掉，不再用
- **需要代理的接口（Deezer/MusicBrainz/Genius）一律不加入 fallback**——用户明确要求只写免密直连的
- **不碰 VIP 破解接口**：付费墙是平台版权保护，只做其他平台免费资源的替代；全平台 VIP 的歌直接返回原值，不伪造

### ⚠️ ④ VIP 判定铁律：不能靠 "streams 为空"（2026-08-19 用户"李荣浩恋人还是只能听1分钟"实测修正）

**错误前提（第一版）**：认为 VIP 歌 `_audio_streams` 返回空 → `if streams:` 有流就用官方。**实测被否**：汽水官方 API 对 VIP 歌**照样返回 3 个音质流**（257K/129K/65K），但这些流只有 **60 秒试听**（`seo_track.track.audition_info.duration_ms=60001` 或 `preview`）——`if streams:` 判断永远命中官方试听流，酷我 fallback 根本不触发，用户"只能听 1 分钟"。

**正确判定**：seo 数据里查 VIP 标记，命中直接跳过官方流走 fallback：

```python
def _is_vip_track(self, data):
    track = (data.get("seo_track") or {}).get("track") or {}
    label = track.get("label_info") or {}
    if label.get("only_vip_playable") or label.get("only_vip_download"):
        return True
    if track.get("audition_info") or track.get("preview"):   # 有试听信息 = 非会员只能听片段
        return True
    return False

# playerContent 顺序：
# ① _is_vip_track(seo) 命中 → _vip_fallback（酷我→抖音）直接返回，跳过官方流
# ② 非 VIP → _audio_streams(seo) 官方流
# ③ streams 仍空（异常）→ _vip_fallback 兜底
```

- 实测热歌榜 15/15 VIP 歌全部正确命中（`only_vip_playable`/`audition_info`/`preview` 至少一个存在），默认听歌模式完整链路（148 首）VIP 歌全部正确切酷我
- **排查"还是只能听 1 分钟"**：先确认手机导入的是含 `_is_vip_track` 的新版文件（旧版无此方法 → VIP 歌走官方试听），再测具体歌曲：`seo=_seo(track_id)` → 打印 `_is_vip_track(seo)` 与 streams 数量（VIP 歌应 streams=3 但 is_vip=True）
