# 特殊策略

iframe：请求 iframe src，使用 urljoin 补全，最多递归 3 层；每层记录响应和提取结果，不能无限递归。

解码：遇到 atob、Base64、Hex、URI、AES、XOR 或 RSA 时，先识别算法和参数，再用 code_runner 验证一条样本；缺少 key/iv/sign 算法时进入阻塞状态。

域名与限流：检测小体积跳转页和域名发现函数，维护候选域名列表；请求限速、超时和失败切换必须有上限。

随机短视频：详情队列第一项固定为点击项，其余从可验证的全库分页随机抽样；去重后保持第一项不变。

上下文队列：音乐等聚合内容的 vod_id 必须编码当前项和上下文；detailContent 解码后重抓上下文列表，使用 URL/ID/hash 定位当前项，禁止只按歌名定位。
