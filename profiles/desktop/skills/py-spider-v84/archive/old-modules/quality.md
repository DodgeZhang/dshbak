# 质量门禁

静态：语法、导入、Spider 类、T4 继承、方法签名、五接口、字段名、线路分隔符、无空壳、无 `__main__`、无精确 class 匹配、无重复请求、无伪分页值。

接口：home 分类有效；category 有列表和分页；detail 有标题、ID、线路；search 可去重并进入详情；player 返回已验证播放地址或明确的阅读/图片协议。

播放：至少完成分类→详情→播放页→最终地址链路。播放页 URL 不得冒充最终直链；需要 Referer、Origin、token 或代理时必须写入 header/策略。

报告：记录每接口状态、样本数、失败原因、修复轮数、降级工具、播放结果和剩余风险。任何门禁失败都不能标记 COMPLETED。
