## 4. 图片：loadBannerDirect 是明文 URL，但内容加密！

- 列表页 `loadBannerDirect('https://pic.xustgq.cn/upload_01/xiao/...jpeg')` → **明文 URL**
- 下载该 URL 的内容**是 AES 加密的**（头 `>\xaap\x8e` 非 JPEG 魔数）
- 正确链：提取 URL → 下载 → AES 解密内容 → JPEG（`ffd8ffe0`）
- 密钥：key=`f5d965df75336270` iv=`97b60394abc2fbe1`（与 51吃瓜 json 相同）
- **json 工具链做不了"下载再解密"**（`源码转b64#解密aes` 是对 URL 解密，必然失败）→ 图片必须 py localProxy
- py 实现：`_img_proxy` 返回 `getProxyUrl()&url=b64&type=img` → localProxy 下载 → `_aes_decrypt_img`

## 5. ⚠️ 羊壳 py 环境致命坑（本次"没数据"真正根因）

**`base.spider.Spider` 基类可能没有 `e64`/`d64` 方法！** 调用 `self.e64()` 直接 `AttributeError` → 整个源崩 → 连分类都不显示。**必须自实现**：

```python
def e64(self, s):
    try:
        return base64.b64encode(s.encode("utf-8")).decode("ascii")
    except Exception:
        return ""
def d64(self, s):
    try:
        return base64.b64decode(s).decode("utf-8")
    except Exception:
        return ""
```

**其他羊壳兼容规则**（对照用户可用 py 文件共性）：
- 不依赖基类的任何工具方法，只依赖 `getProxyUrl()`（标准）
- `sys.path.append('..')` 必须有（用户文件都有）
- **`self.classes` 必须在域名解析之前设置**——解析异常时 init 中断，分类不初始化 → 整个源空白
- 域名解析整体 try/except 包裹，永不抛异常
- Crypto 导入 try/except 降级（无 Crypto 时列表照常，仅图片不解密）
- 5 秒线程超时保底：`threading.Thread(worker).join(5.0)`，超时切保底域名

## 7. 页面解析要点

- 数组：`<meta itemprop="dateModified"` 分割文章块
- 标题：首页 `itemprop="headline">&&<div class="wrap"`（带热搜标签），分类/搜索页 `</h2>` 结尾——**两种边界都要兼容**！
- 副标题：`itemprop="datePublished" content="..."` 前 10 位日期
- 链接：`/archives/{id}/`
- 分类：`category/{cid}/`（第 2 页起 `category/{cid}/page/{pg}/`）
- 搜索：`search/{wd}/`（中文要 urllib.parse.quote）
- 播放：`"video":{"url":"https://...m3u8"` 或裸 m3u8 正则
- 类型筛选：filters 按分类分组（json"类型"字段），categoryContent 里 `ext.get("类型")` 覆盖 cid
- 往期内容/标签云：新主题已无（archives/page 空、tags 404），不再加
