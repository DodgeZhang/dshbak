# 404自动挡 域名轮询 + play_data 解密（用户实战验证）

> 来源：用户 404.json 规则（2026-08-12）+ 实测验证
> 站点：404xav（GitHub Pages 发布页 + 数字前缀域名 + zlib 加密播放地址）

## 1. 域名自动获取（两种格式轮询）

发布页源码结构：
```js
const urls = [
    'https://4042604.one', 'https://4042604.pro',
];
```

**两种截取格式（XBPQ 写法）：**
```json
"主页url-c": "https://404xav.github.io/url8/[工具:源码#const urls = *'截取',∬const urls = *'*',*'截取']"
```
- 格式1 `const urls = *'截取'` → 取第一个域名（4042604.one）
- 格式2 `const urls = *'*',*'截取'` → 取第二个域名（4042604.pro）
- **∬ = 多候选**：第一个失败自动用第二个

**数字前缀（4位随机）：**
```json
"前缀": "0123456789[工具:随机字符-4]",
"域名-c": "{{主页url-c}}[替换:https://>>https://{{前缀}}.]"
```
→ `https://4042604.one` + 前缀 `7147` → `https://7147.4042604.one`

**Python 实现要点（py 源轮询）：**
- 格式1：`re.search(r"const urls\s*=\s*\['([^']+)'", html, re.S)` 取第一个
- 格式2：`re.findall(r"'([^']+\.(?:one|pro|com|cc|us))'", html)` 取第二个
- **5 秒内无数据（HTTP 非 200 或超时）→ 自动切换另一格式/域名**
- 前缀：`random.choices("0123456789", k=4)` 4 位数字

## 2. play_data 解密（base64 + raw deflate）

详情页：
```js
var play_data = "TVBJUsQwDPyLz0NiR7Zs5..."  // base64 编码
```
解密 JS（before.js 里的 decodeDeflateBase64）：
```js
atob(play_data) → Uint8Array → pako.inflate() → JSON.parse → TextDecoder
```

**Python 实现（关键：raw deflate，wbits=-15！）：**
```python
import base64, zlib, json

pd = re.search(r'var play_data\s*=\s*"([^"]+)"', html).group(1)
raw = base64.b64decode(pd)
d = zlib.decompressobj(-15)          # ← raw deflate，不能用 zlib.decompress
text = d.decompress(raw).decode('utf-8', errors='ignore')
data = json.loads(text)
# data 结构: {"info": [标题, 封面, 时长], "video": "https://cdn-video.404bt.top/91/xxx.m3u8", "author": "...", "frame": 1}
play_url = data["video"]
```

**踩坑：**
- `zlib.decompress()` 报 "incorrect header check" → 必须用 `decompressobj(-15)`（pako 默认 raw deflate 无 zlib 头）
- 标题/作者是 unicode 转义（`\u5077`）→ `data["info"][0]` 已由 json.loads 自动解码

## 3. 列表结构（首页/分类）

```html
<div class="cell_box">
  <div class="v_thumb"><a href="/detail/91web/xxx.html">
    <img data-original="https://.../thumb/xxx.jpg">
    <div class="v_tag">91资源</div></a></div>
  <a href="/detail/91web/xxx.html">
    <div class="v_time"><i class="fa fa-clock-o"></i>00:04:56</div>
    <div class="v_title">标题(HTML实体编码&#x5077;...)</div></a>
</div>
```

**解析要点：**
- 块边界：`<div class="cell_box">` 开始
- 链接：`<a href="/detail/{分类}/{hash}.html"` → vod_id
- 图片：`<img data-original="&&"`
- **标题是 HTML 实体编码** → 用 `html.unescape()` 或 `html_parser.unescape()` 解码
- 分类页：`{{域名-c}}/list/{cateId}/0/1.html`（;;z 直接播放）
- 搜索：`{{域名-c}}/search/cangku/{wd}/{pg}.html`
