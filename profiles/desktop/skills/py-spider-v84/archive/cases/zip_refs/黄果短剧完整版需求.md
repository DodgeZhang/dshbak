## 播放三种情况（#8 最重要）

```html
<!-- a) 单集：直接 data-play-src -->
<article class="hg-play__slide is-active" data-play-id="1003" data-play-src="https://yd-hls.utxxds.cn/m3m/xxx.m3u8?auth_key=...&amp;v=3">

<!-- b) 多集：集数列表在 /video/xxx/ 视频页（不是详情页！） -->
<div class="hg-play__episodes">
  <a class="hg-play__ep-item is-active" href="/video/1197/" data-ep-id="1">01</a>
  <a class="hg-play__ep-item" href="/video/1197/ep-2/" data-ep-id="2">02</a> ...
</div>
<!-- 每集再请求该集视频页 → 同 a) 提取 data-play-src -->

<!-- c) 吃瓜：文章正文多个播放器 -->
<div class="post-video-player" data-player-key="post-1" data-src="https://yd-hls.utxxds.cn/videos5/xxx.m3u8?...">
```

py 源 detailContent 流程：详情页找 `/video/\d+/` 链接 → 请求视频页 → 先试 `hg-play__episodes` 集数列表，无则 `data-play-src` 直连 → 都无则 `post-video-player data-src` → 兜底给视频页链接。

## 本 session 踩坑（都修好了）

1. **集数在视频页不在详情页**：`/detail/xxx/` 页面没有 `hg-play__episodes`（我第一次只查详情页，播放走了兜底）→ 必须请求视频页
2. **搜索格式是 `/search/?q=关键词`（GET）**，不是 `/search/关键词/`（404）。表单 `<form action="/search/" method="get">`，参数名 `q`
3. **搜索卡片结构不同**：`<div class="hg-drama-card">` 无 `data-track-id/attr`、无 `hg-drama-card__tags` 结束标记，标题在 `hg-drama-card__title` div → 标题兜底链：`data-track-title` → `alt` → `hg-drama-card__title`
4. **categoryContent 的 pg 是字符串**：`pg + 1` 报 TypeError（can only concatenate str）→ 函数开头 `pg = int(pg) if str(pg).isdigit() else 1`（玩物社区同样踩过）
5. **详情页图片优先级**：首个 `data-src` 常是 `--><!--` 注释残留 → 用 `data-src="(https://[^"]*(?:upload|pic)[^"]*)"` 过滤；主图特征 `upload_01/xiao/...jpg`（静态封面），推荐位是 gif（用户反馈"图片不对"后从 gif 改到 xiao jpg）
6. **排行榜卡片标题**：`hg-rank-item` 用 `data-track-title`，简介 `hg-rank-item__desc`，热度 `hg-rank-metric-value`
7. **专题 folder**：一级 `vod_tag="folder"` + vod_id=`/topics/xxx/`；detailContent 遇 `/topics/` 返回空 list 让播放器走 categoryContent
8. **吃瓜标题在 `<h3>`**（不是 img alt），meta 在 `hg-post-card__meta`（作者/日期/分类）
